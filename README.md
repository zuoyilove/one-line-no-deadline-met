A single-line joke giving an excuse for missing a deadline, written by `main.ts` to `/output/entry.txt`: "I treated the deadline like a group project partner and assumed someone else was handling it — turns out I was the someone else." (128 characters, one sentence, no setup line. The punch lands on the speaker discovering they were the "someone else" all along.)

The line is a fixed string in `main.ts`; running the program writes it byte-for-byte to `/output/entry.txt`, so every run produces the same 128-character entry.

## Run it

```sh
node main.ts
```
